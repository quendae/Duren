# Dureń / Durak

**Классический «Дурак», полностью работающий офлайн прямо в браузере.**

[English](README.md) · [Polski](README.pl.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

Ничего устанавливать не нужно: не требуется ни сервер, ни аккаунт. Вся игра находится в одном файле `durniak.html` — скачай его, открой в современном браузере и играй.

## Что есть в игре

- Классическая колода для «Дурака»: **36 карт от 6 до туза**
- Один игрок и **1–3 компьютерных соперника**
- Отдельная сложность для каждого бота: **Легко, Нормально, Сложно, Эксперт**
- Дополнительное правило **переводного дурака**
- Необязательный лимит в шесть карт на атаку
- Можно разрешить подкидывать всем игрокам или только бьющему
- Режим новичка с подсветкой доступных карт и контекстными подсказками
- Пошаговое обучение с управляемой тренировочной партией
- История раунда и правила прямо во время игры
- Анимации карт и простые звуки стола
- Три скорости хода ботов
- Автоматическое локальное сохранение и продолжение партии
- Адаптивный интерфейс для небольших экранов
- Языки интерфейса: **польский, английский, немецкий и русский**

## Как играть

1. Скачай [`durniak.html`](durniak.html).
2. Открой файл в современном браузере.
3. Выбери **Новая игра** или начни с **Как играть**, если ещё не знаком с правилами.

На этом всё. После загрузки файла игре не нужен интернет и не требуются внешние зависимости.

## Кратко о правилах

Каждый игрок начинает с шестью картами. Одна открытая карта лежит поперёк под колодой и задаёт козырную масть на весь раунд.

Бьющий кладёт карту. Кроющий должен отбить её старшей картой той же масти или козырем. Козырь можно побить только старшим козырем. Подкидывать можно карты тех рангов, которые уже есть на столе.

Если кроющий не может или не хочет отбиваться, он забирает карты. После каждого хода игроки добирают до шести карт, пока в колоде ещё есть карты. Когда колода заканчивается, игрок без карт выходит из игры.

Последний игрок, у которого остаются карты, становится **дураком**.

## Сложность ботов

Уровни сложности отличаются не только скоростью хода. На более высоких уровнях боты используют всё более сильную логику принятия решений.

- **Легко** — более свободная и частично случайная игра.
- **Нормально** — предпочитает дешёвые атаки и разумную защиту.
- **Сложно** — учитывает ценность карт, повторяющиеся ранги и состояние колоды.
- **Эксперт** — дополнительно оценивает неизвестные карты, риск защиты и темп концовки.

В одной партии каждому боту можно назначить свой уровень сложности.

## Дополнительные правила

Перед началом игры можно настроить несколько распространённых вариантов «Дурака»:

- **Все могут подкидывать** — если выключить, дополнительные карты может класть только игрок, начавший атаку.
- **Переводной** — кроющий, который ещё ничего не отбил, может перевести атаку следующему игроку картой того же ранга.
- **Лимит в шесть карт** — его можно отключить, чтобы атаки были менее ограниченными.

## Сохранение и приватность

Настройки, статистика и — если включено сохранение — текущая партия хранятся локально в браузере через `localStorage`.

Игре не нужно отправлять данные на сервер. Очистка данных сайта в браузере может также удалить сохранённую партию.

## Техническая информация

Проект специально сделан максимально простым для запуска и переноса:

- один самодостаточный HTML-файл
- обычные HTML, CSS и JavaScript
- без сборки
- без фреймворка
- без внешних ресурсов, необходимых во время игры

Поэтому игру легко хранить на компьютере, флешке или в любом другом месте и запускать полностью офлайн.
