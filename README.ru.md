# Dureń / Durak

Браузерная версия классического «Дурака» на 36 карт с офлайн-игрой и сетевым мультиплеером.

[English](README.md) · [Polski](README.pl.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

## Возможности

- колода 36 карт от 6 до туза
- 1–3 компьютерных соперника в офлайн-режиме
- уровни ботов: Easy / Normal / Hard / Expert
- опциональный переводной вариант
- опциональный лимит в шесть карт
- подсказки для новичков и обучение
- адаптивный интерфейс
- польский, английский, немецкий и русский языки
- сетевые комнаты через общий игровой сервер QQND
- партии на 2 игроков, 3 игроков и 2 игроков + бот
- восстановление соединения с 60-секундным окном возврата

## Запуск

Для размещённой версии точкой входа является:

```text
index.html
```

Необходимые runtime-файлы:

```text
index.html
durniak-offline.html
multiplayer.css
multiplayer.js
mp/
  core.js
  game.js
  network-server.js
```

`index.html` — публичная точка входа. `durniak-offline.html` содержит движок и интерфейс самой игры и по-прежнему может открываться напрямую для офлайн-режима.

## Архитектура мультиплеера

Онлайн-режим подключается по WebSocket к общему backend QQND на `api.qqnd.fyi`. Cloudflare Worker и WebRTC-сигналинг больше не входят в этот репозиторий.

Сейчас Duren работает по модели host-authoritative: браузер хоста выполняет правила и отправляет каждому удалённому игроку приватное представление состояния. Следующий этап — перенос полного игрового движка на сервер.
